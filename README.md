# Fight Arena v0.8 — Ultron Update

Mobile-first 1v1 fighting game built for iPad landscape.

## v0.8
- Rookie remains the default balanced fighter.
- El Primo is purchasable for 1,000 coins and plays as a tank.
- Level 1: Nightfang — Easy — 100 HP — 100 coins + 25 XP.
- Defeating Nightfang unlocks Level 2.
- Level 2: Ultron — Normal — 125 HP — 110% damage — 175 coins + 40 XP.
- Ultron uses the project's original robot design and has a ranged Energy Pulse.
- Coins, gems, XP, character ownership, selected fighter and campaign unlocks save locally in the browser.
- Touch joystick is mapped correctly: left = left, right = right.
- Punch, kick, jump, block and special controls are included.

## Development rule
v0.8 is the new GitHub baseline. Future versions should preserve working systems and make focused changes rather than replacing the entire game unnecessarily.

Open `index.html` to run the game. For iPad, deploy the repository with a static host such as GitHub Pages.
